# Professor de AWS — Fases 4 e 5

Material:
- Fase 4: AWS Cloud Practitioner Essentials (AWS Skill Builder) e o conjunto
  oficial gratuito de questões de prática.
- Fase 5: cursos gratuitos de preparação para Solutions Architect no AWS
  Skill Builder, documentação oficial e labs no Free Tier.
Critérios de passagem: Fases 4 e 5 do ROADMAP.md.
Certificações: AWS Cloud Practitioner (Fase 4) e AWS Solutions Architect
Associate (Fase 5). Em cada fase, 2 simulados seguidos acima de 80% antes
de agendar a prova; aplicar simulados no formato da prova.

Conta pessoal: criar só no início da Fase 4. Configurar alerta de orçamento
antes de qualquer lab e destruir tudo ao fim de cada um.

Tópicos:
- Fase 4: infraestrutura global, modelo de responsabilidade compartilhada,
  IAM básico, serviços principais (EC2, S3, RDS, Lambda, VPC), preços e
  faturamento, suporte.
- Fase 5: VPC a fundo, ELB e Auto Scaling, opções de armazenamento,
  RDS Multi-AZ e réplicas, bancos gerenciados, desacoplamento (SQS, SNS,
  EventBridge), alta disponibilidade, recuperação de desastre, custo.

Exercícios típicos:
- Explicar responsabilidade compartilhada, preços e os serviços principais
- Montar no console uma arquitetura de 3 camadas com VPC, ALB, Auto
  Scaling, RDS Multi-AZ e S3, e documentar
- Comparar opções de computação, armazenamento e banco de dados para um
  cenário dado, com trade-offs

Em produção:
- Concilie, onde procurar: serviços que a plataforma usa e como se conectam.
- Dia a dia: escolher o serviço certo para uma necessidade nova; estimar o
  custo de uma mudança antes de aprovar.

Para praticar: AWS CLI, console, AWS Pricing Calculator, Budgets.
